4. NO EXPLICIT TIMEOUT FOR RPC REQUESTS
   ──────────────────────────────────────────────────────────────────────────
   Issue: ethers.js calls don't have timeout enforced → hanging requests
   
   Affected Functions:
   └─ RPCProvider.call() (line 320+): No Promise.race(...timeout)
   
   Fix (30 min):
   ```typescript
   // Wrap ethers calls with timeout
   private async callWithTimeout<T>(
     fn: () => Promise<T>,
     timeoutMs: number = 30_000
   ): Promise<T> {
     return Promise.race([
       fn(),
       new Promise<T>((_, reject) =>
         setTimeout(() => reject(new Error('RPC timeout')), timeoutMs)
       )
     ]);
   }
   ```

   Problem Scenario:

   - Multiple threads try to insertToken(...) simultaneously
   - SQLite locks on write → some queries timeout

   // Add transaction wrapper for atomic operations
